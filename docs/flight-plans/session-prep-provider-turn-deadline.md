# Bounded Session Prep provider chat

Tier 2: provider service authority, canonical conversation and model usage.
This Sovereign sender increment is built on merged PR77's source-only review
wrapper. Deploy the independently reviewed Core PR796 receiver first; its
shared 10 turns/60s and two unfinished 195-second reservations use existing
canonical rows. No schema, external limiter or deployment setting is added.

For the platform provider profile, one monotonic 180-second total budget starts
before Core mount resolution and canonical acceptance. Model/tool work is
cancelled after 165 seconds; the remaining budget bounds SDK cancellation,
exact metadata settlement and canonical closure. The same coroutine preserves
request-local ContextVars. Legacy/public requests retain their current path,
and deterministic emergency guidance still precedes every authority gate.
Client cancellation propagates without inventing a final or restarting work.

Core's fixed, validated provider-chat 429 maps to the existing public
RATE_LIMITED problem and bounded Retry-After. A known admission rejection gets
one write attempt and no hidden retry or model call. Uncertain transport still
uses existing same-key retries; a replayed accepted phase still cannot rerun
models. No browser identity, body persona or overbroad capability changes this.

Deadline closure distinguishes observed receipts from ambiguous delivery.
Unknown user or source/history receipt delivery cannot create a guessed final.
With acknowledged acceptance and dependencies, discard any partial draft,
citations and documents, then attempt the existing static unavailable final
through all unchanged Core expiry/revocation/source/history fences. If final
transport had already started, only its exact payload may be retried; a
different timeout answer would conflict with canonical state. An uncertain
final/audit completion returns a non-retryable 503 so the existing stored-turn
status workflow can establish what was accepted. No successful clinical answer
is inferred from runtime identity or a timeout.

Before usage transport, retain its exact immutable metadata event. Bounded
settlement reuses that same event, timestamps and actual succeeded/failed/
cancelled status; it never invents counters or receipts. A missing receipt
keeps terminal usage/audit closure pending. Cancellation of local SDK transport
is not proof that the remote vendor stopped work or refunded it. Closure can
remain incomplete when authority changes or its fifteen-second budget ends;
Core's accepted phase is retained and its reservation ages out conservatively.
