# Actual-answer context for reviewed quotations

Risk: Tier 2. This isolated provider source integration is authorized for the
Session Prep operational beta. Publication and any exact-image release remain
separate root-owned decisions. No authority, schema, credentials, deployment,
public model fields or citation consumer changes are part of this increment.

## Particular answer and covered boundary

The existing BAA evidence selector returns its original whole-section indices
plus a closed vocabulary describing the complete actual question, every source
and section, and exactly the selected excerpts. Its observations are fallible
semantic classifications, not a doctrinal verdict or proof of moral safety.
The server copies the same source sections and binds those observations to the
exact question, full source enumeration, canonical answer, original coordinates
and negotiated optional citation namespace. No fixture identity routes requests.

The required LOW/ENGAGEMENT review uses that private binding only after all
existing neutral eligibility, full-context moral and HIGH vetoes. A finite
value-free frame describes this particular historical answer's moral posture.
Magisterium receives no question, clinical passage, value, date or source handle
from this lane. Missing, unknown, unsafe or changed observations produce the
static evidence-unavailable outcome with required review, never a generic-policy
or raw-source fallback. A conforming awaited review must still pass the same
binding again before the original answer and optional namespace can be forwarded.

The actual-answer system, header and question ask for a judgment about this
represented answer. They explicitly permit refusal for insufficient context and
do not assume conformance. The legacy policy option and HIGH/general wrappers
retain their existing behavior. Any condition anywhere in a bounded assessment
still refuses. An explicit corresponding judgment plus only the narrow excluded
clinical-accuracy limitation can reach the unchanged duplicate-safe strict
boolean parser; neither that recognition nor a valid frame grants conformance.

## Calls and preservation

Selected answers reuse one existing covered selector call, now capped at 4,096
tokens to enumerate the closed descriptor. The deterministic timeline adds one
covered posture assessment, capped at 4,096 tokens and ten seconds within the
existing absolute work deadline; there is no retry or extension. Original
section/aggregate/count limits, source notices, answer envelope, disclaimers,
citations, grants, review failure presentation, exact final receipt, usage and
deadline closure remain in force. Private fields never enter public JSON.

## Local evidence and release limits

Offline cases retain the complete original six MD questions and their appropriate
two-section fictional quotes across all four routed intents. They exercise the
actual native selector, binding, orchestrator and arbiter with explicit scripted
model/transport responses. Positive fixtures now explicitly supply closed
historical observations. Missing-context and refusal cases remain negative;
original policy assessment cases additionally exercise the direct legacy arbiter.
Mutation, reordered/same-day namespace, timeline, strict parser, scope, PHI,
review-disposition and deadline checks are source qualification only.

A separately reviewed fixed value-free context-sufficiency diagnostic can assess
the new task framing. It is not an actual patient turn or an explanation of an
earlier UI failure. Offline acceptance cannot establish vendor semantic accuracy
or live readiness. Root owns independent final source review and any authorized
diagnostic, normal publication, exact-source release and unchanged full-question
acceptance. Recovery is a normal source revert and separately reviewed image
promotion; it never relaxes mandatory review or the clinical egress boundary.
