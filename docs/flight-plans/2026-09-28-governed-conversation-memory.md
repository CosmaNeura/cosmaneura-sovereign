# Governed recent conversation — Tier 2 flight plan

Clinicians can reopen the current encounter's recent conversation and check an
uncertain response without running the question again. Supported drafts consume
bounded, server-selected history; every read, including an empty snapshot, binds
its exact receipt at canonical final acceptance. Core owns scope, revocation,
source freshness, original prep expiry, and transitive dependency validation.

Release is receiver-first: independently review and merge Core's governed
conversation receiver, then this Sovereign consumer, then the Core host adapter
and immutable asset pin. Use the canonical local build/publish/deploy path under
the existing staging delegation while Actions remain disabled. Root records
fresh live baselines and receipts before each promotion. Keep the existing
provider cohort and release controls; no new flags, schema, dependencies, Scribe
changes, or broader data access are part of this release.

Verify synthetic recent-history hydration, pending/stale omission, exact stored
response recovery, a follow-up that uses an earlier answer, and changed-source
409 suppression. Verify current encounter switching and authorization loss
clear the panel. Replaying an accepted UUID must never rerun model work.

Recovery: restore the preceding reviewed Core asset pin/host adapter and
Sovereign image through the same canonical staging controller. Core's additive
receiver remains compatible with callers that never read history. Do not remove
a history reference from an already-read turn to bypass a conflict.

Limits: at most six recent encounter turns / twelve messages / 192 KiB; no
pagination or unlimited memory. Inference excludes pending, stale, refused,
unavailable, emergency, and sensitive-disclosure answers. Recovered text keeps
its canonical presentation; cards, citations, and downloads are not reconstructed.
Session Prep remains summary-only. Missing or outdated context requires a new
question; reading status does not restart abandoned work. A final independent
review of the pushed head is required before merge.
